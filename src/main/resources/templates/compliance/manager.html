사용 방법
  1. 좌측 (Category): 매핑을 관리할 KISA 표준 카테고리를 선택합니다.
  2. 우측 (All Rules): 연결할 내부 취약점 룰(Rule)을 검색합니다.
  3. 추가 (Add): 우측 룰을 선택 후 Add Selected 버튼을 누르거나, 중앙 영역으로 드래그 앤 드롭합니다.
  4. 삭제 (Remove): 중앙 목록에서 룰을 선택하고 Remove Selected 버튼을 누릅니다.
상태 표시
  • New 초록색 텍스트
    사용자가 직접 추가한 커스텀 매핑입니다.
  • Deleted 빨간 취소선
    시스템 기본 매핑이지만 사용자가 삭제(비활성화)한 항목입니다. 다시 추가하면 복구됩니다.
  • 검정색 기본 텍스트
    시스템 기본(Default) 매핑 상태입니다.
